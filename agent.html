Demonstrating how Gemini in Chrome (Side Panel Agent) discovers webpage WebMCP tools to assemble travel bookings, using WebAuthn Immediate UI (uiMode: 'immediate') as the 1-second biometric authorization checkpoint.

Gemini Side Panel + WebMCP
How the Side Panel + WebMCP Architecture Works: The user gives a travel prompt to Gemini in Chrome (Side Panel). Gemini calls the webpage's WebMCP tools (search_flights, select_seats, prepare_checkout) to build the itinerary in the DOM. When Gemini issues the final booking call, the site triggers Immediate UI to prompt the human's fingerprint for a 1-second cryptographic authorization—with zero passwords or API keys shared!
