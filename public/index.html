Immediate UI Mode for Web Logins (uiMode: 'immediate')

Immediate UI mode is a unified web platform capability designed to streamline sign-in flows by proactively offering saved passkeys and managed passwords directly to users when they reach a sign-in moment—such as clicking a Sign In, Checkout, or Like button.

Why use Immediate UI Mode? (Core Benefits)

🚀 Skips Cross-Device Options

Fail-Fast

Some users are confused by QR code dialogs for cross-device flows. Immediate UI mode fails fast and throws a NotAllowedError immediately when there are no available credentials, avoiding external key/QR interruptions.

👤 Accounts over Credentials

Intuitive UX

Immediate UI mode displays a friendly list of user accounts with avatars instead of generic credential prompts. The browser intelligently picks the best available sign-in option (passkey or password).

⚡ In-Context Sign-in

Zero Detour

Users can authenticate dynamically right where they are—before checking out, when liking a post, or downloading a resource—without detouring to a separate sign-in page and losing their state.

🛡️ Progressive Enhancement

Graceful Fallback

If the browser doesn't support immediate UI mode or if no credentials exist, the API rejects silently. Your site can gracefully fall back to existing sign-in forms or guest checkout.

Feature Detection & Basic API Call Reference

// 1. Check feature support before offering immediate UI mode
const capabilities = await PublicKeyCredential.getClientCapabilities();
if (capabilities.immediateGet) {
  console.log("Immediate UI mode is supported by this browser.");
}

// 2. Request credentials with uiMode: 'immediate'
try {
  const cred = await navigator.credentials.get({
    password: true, // Include password credentials
    publicKey: {
      challenge: serverGeneratedChallenge,
      rpId: 'example.com'
    },
    uiMode: 'immediate'
  });
  // Handle successful sign-in with cred
} catch (error) {
  if (error.name === 'NotAllowedError') {
    // Fails fast! User cancelled or no saved credentials exist.
    // Show fallback UI: standard sign-in form, guest checkout, etc.
    showFallbackUI();
  }
}
